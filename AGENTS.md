# AGENTS.md

## ЗАПРЕЩЕНО: проверки в браузере

Никогда не запускать headless-браузер и не делать скриншот-проверки. Ни Puppeteer,
ни Playwright, ни Chrome в headless-режиме, ни `window.__ready`, ни `readPixels`,
ни ожидание `scene.executeWhenReady`. На таких проверках сессия зависает часами,
и пользы от них почти нет: они проверяют то, что уже видно из кода.

**Как проверять вместо этого:**

- синтаксис JS — `node --check`;
- структура и корректность GLB — официальный валидатор
  (`/tmp/val.js`, пакет `gltf-validator`), он даёт точные коды ошибок;
- JSON-части GLB — обычным Python;
- логика в браузере — чтением кода, без запуска.

Один запуск headless-браузера допускается только если пользователь явно
попросил. Ошибка или зависание браузера — не повод повторять прогон.

## Правило на ошибки

Одна ошибка — одно исправление, затем сразу следующий шаг. Не гонять цикл
«прогнал — упало — поправил — прогнал» более двух раз подряд. Если после двух
попыток не заработало — остановиться и сказать пользователю, что именно
блокирует, вместо бесконечных прогонов.

## Проект: конвертер моделей GTA 5 для Babylon

- `auto/sultan.yft`, `auto/sultan.ytd`, `auto/sultan+hi.ytd` — исходники, **не
  изменять никогда**.
- `web/car.glb` — базовая модель (27 597 408 байт, 147 мешей), тоже не трогать.
  Всё новое пишется отдельными файлами.
- `web/index.html` — просмотрщик. Умеет `?model=файл.glb`, выбор файла с диска
  и drag-and-drop.
- `tools/gta_lights_fix.py` — правит цвет фонарей в готовом GLB.
- `tools/glb_convert.py` — универсальный конвертер через Blender.

### Устройство фонарей — не перепутать снова

Цвет линз **уже запечён в атласе** `vehiclelights128`, домножать его на цвет
из carcols нельзя, получится двойная окраска. Попиксельно по реальным UV:

| группа | RGB атласа | R:G:B |
|---|---|---|
| taillight | 0.320 0.044 0.043 | 1.00 : 0.14 : 0.13 |
| brakelight | 0.503 0.027 0.009 | 1.00 : 0.05 : 0.02 |
| indicator | 0.390 0.121 0.003 | 1.00 : 0.31 : 0.01 |
| headlight | 0.338 0.330 0.379 | 0.89 : 0.87 : 1.00 |
| reversinglight | 0.377 0.393 0.465 | 0.81 : 0.85 : 1.00 |
| extralight | 0.427 0.422 0.412 | 1.00 : 0.99 : 0.96 |

Настоящий баг исходного `car.glb` был в другом: у материала `vehiclelights128`
нет `baseColorTexture`, атлас висит на `emissiveTexture` с `emissiveFactor 0.5`,
шейдера `vehicle_lightsemissive` в glTF нет — фонари выходят серыми. Лечится
переносом атласа в `baseColor` с белым множителем.

### Границы платформы

Прямой импорт бинарного `.yft` на macOS невозможен: `szio` отдаёт весь бинарный
путь библиотеке `pymateria`, а она только под Windows и отсутствует на PyPI.
Рабочий маршрут на macOS — CodeWalker XML → Sollumz → GLB.
